Lattice
The lab Code

Two people. One note. Zero conflicts.

Lattice is a whiteboard where edits made at the same time, offline, in any order, always merge into the same board for everyone. No server deciding who wins. No “someone else changed this file”.

Break the network yourself

Built from scratch on Conflict-free Replicated Data Types by Shapiro, Preguiça, Baquero and Zawirski (SSS 2011). No CRDT library, no Firebase.

This is running live in your browser. Type in either box, cut the network, and reconnect.

Three data types from the paper do all the work.

OR-SetObserved-Remove Set

Which notes exist. Deleting a note removes only the copies you have seen, so if a friend edits it while you delete it offline, their version survives instead of silently vanishing.

LWW-MapLast-Writer-Wins registers

Position, size and colour. Each value carries a hybrid logical clock timestamp, so two people dragging the same note agree on where it ends up without asking a server.

RGAReplicated Growable Array

The text inside notes. Every character has a unique id and remembers what it was typed after. Deleted characters stay as invisible anchors, so two people typing in the same sentence never scramble each other's words.

It's tested like a theorem, not a demo.

The paper proves that if every replica eventually gets every change, they all end up identical. The test suite tries to prove it wrong: thousands of random editing sessions over a network that delays, reorders, loses, duplicates and splits messages.
